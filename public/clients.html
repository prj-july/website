Compatible clients

Clients for your Project July oven

Every way to control a June oven running Project July (June Local). June's cloud is gone, so each of these talks to the oven directly on your home network.

Choose a client: the Home Assistant integration, the Android companion app, or the Apple companion app (the Apple app may need TestFlight). Searching for “Project July” also finds them.

  • Android
  • Apple

Which install did you choose?

The installer offers two: Install June Local, the standard install that keeps June's certificate, and Install with your own CA, the custom install that makes a certificate just for your home. Some clients need one extra step after a custom install. Certificates, explained.

Home Assistant integration

BetaUpdated 4 Oct 2026

Adds your June oven to Home Assistant: on/off and cook modes, target and current temperature, cook progress, preheat-ready and done sensors, food probe, and the interior camera on demand. Working on real ovens; it has no tagged release yet.

Install
Either install. Home Assistant 2025.1 or newer, and HACS (as a custom repository) or a manual copy.
Oven address
The oven's IP address or hostname. The standard install's certificate covers june.local, june2.local and june3.local; for the IP address or a name of your own, use your own CA, which puts it in the certificate.
Certificate
Your own CA: paste your home's ca.crt into CA certificate (PEM) when adding the oven, or later under Configure. Standard install: turn off Verify TLS certificate instead.
Pairing
You type an eight-digit code on the oven's Connect screen.

Android companion app

BetaUpdated 4 Oct 2026

The June app you know, rebuilt to talk to June Local: it looks and works like June's app, but connects to your oven's address instead of June's servers, and no longer refuses your home's certificate.

Download
It comes with the installer. When the install finishes, open Phone setup and tap Download the companion app, or scan the code it shows. It isn't offered as a separate download yet.
Install
Either install. Your own CA: first install your home's ca.crt on the phone, under Settings › Security › Encryption & credentials › Install a certificate › CA certificate.
Endpoint
Root, or an ADB shell with root, to point the app at your oven. An in-app setting is planned.
  1. Install the app from the installer's Phone setup.
  2. Set the endpoint to your oven's address:
    adb shell setprop persist.june.local_endpoint <oven-address>
  3. Open the app and pair from the oven's Connect screen.

The Project July app, the same app as on iPhone, is also being tested on Android. It will be listed here when it's ready.

Apple companion app

TestFlightUpdated 4 Oct 2026

The Project July app for iPhone: preheat, change the temperature, timers with +1/+5/+10 minutes, and the live camera beside the temperature. You pair it once by typing a code on the oven. It's in testing, so TestFlight may be required.

Download
There's no public TestFlight link yet. Email hello@project-july.org to ask for an invite, then install Apple's free TestFlight app to accept it.
Install
Either install. Your own CA: send ca.crt to the iPhone (AirDrop or email), install the profile, then turn it on under Settings › General › About › Certificate Trust Settings.
Oven address
Typed in the app on first launch. No root or computer needed.

Web browser

StableUpdated 4 Oct 2026

Every oven running June Local serves a status page. It's the quickest way to check the oven is up after an install. It shows status only; use one of the apps or Home Assistant to cook.

Install
Nothing to install, with either install. Any browser on the same network as the oven.
Address
Open http://<oven-ip>/local, using your oven's IP address.
For advanced users

http://<oven-ip>/local/status returns the same as JSON, for scripts and monitoring: {"ok": true, "mode": "local", "server": "june-local", …}. The oven's API and WebSocket are on https://<oven-ip> (port 443), with the same routes June's cloud used.

July Oven dashboard card

BetaUpdated 4 Oct 2026

A Home Assistant dashboard card styled after the oven's own glass screen: status, a one-tap Stop, add-time buttons, the camera, and the oven's cook modes when it's off. It handles several ovens on one card.

Install
Comes with the Home Assistant integration; there's nothing extra to install. Reload the browser tab once after updating.
Add it
Search for “July Oven” in the card picker, or in YAML: type: custom:july-oven-card.
