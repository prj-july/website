Web browser

Stable

Every oven on Project July serves a status page. It’s the quickest way to check the oven is up after an install. Status only: use the app or Home Assistant to cook.

Open, from any device on your networkhttp://<oven-ip>/local

For scripts and monitoring

/local/status returns the same as JSON: {"ok": true, "mode": "local", "server": "june-local", …}. The oven’s API and WebSocket are on port 443 (https://) and port 80 (http://), with the same routes June’s cloud used.

June’s original app, rebuilt

Android · needs root

June’s own Android app, pointed at your oven instead of June’s servers. Most people should use the Project July app instead.

How to set it up
  1. Get it from the installer: open Phone setup and tap Download the companion app, or scan the code it shows.
  2. With root, or an ADB shell with root, point it at your oven:
    adb shell setprop persist.june.local_endpoint <oven-address>
  3. After the custom install only: add ca.crt under Settings › Security › Encryption & credentials › Install a certificate › CA certificate.

Certificates are optional

Every client works with either install, and commands are signed either way. After the standard install there’s nothing to do. After the custom install (Install with your own CA), give a client your home’s ca.crt if you want the connection checked.

Where each client takes it
Project July app
Paste it under Home certificate. Without it, the app uses port 80.
Home Assistant
Paste it into CA certificate (PEM), now or later under Configure. Or use http://<oven-ip>:80, or turn off Verify TLS certificate.
June’s app
Install it on the phone as a CA certificate (step 3 in its setup above).
