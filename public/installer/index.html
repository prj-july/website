Installer guide

Make the USB stick and run the installer

The installer runs on a laptop, started from a USB stick. This page shows how to make that stick with the June USB app (or with Ventoy), and what each screen of the installer looks like.

Opening the oven and finding SW2 is covered in the 3D setup walkthrough.

Beta · version 0.7 Ready for testers, not for everyone yet

Installer 0.7 is out for beta testing. We're collecting feedback from testers and fixing what they find, so tell us how it went at hello@project-july.org. If you're less comfortable with technical steps, please hold off until more people have tested it.

Whoever you are, make a backup first. It takes 15 to 30 minutes, and the installer can restore the oven from it if anything goes wrong. How to back up and restore

Making the stick erases it

Everything on the stick is deleted, whether you use June USB or Ventoy. Copy off anything you want to keep, and check twice that you've picked the stick and not another drive.

The installer rewrites the oven's storage

Installing or restoring writes to the oven's built-in storage (its eMMC). Make a backup first so you can always put the oven back the way it was.

Step 1

Download June USB

June USB is a small app for Windows 10 and 11 and macOS 13 or later that makes the stick for you. It downloads the latest installer image from downloads.project-july.org, checks it, and prepares the stick. You don't need Ventoy or anything else.

June USB for Windows June USB for Mac

On Linux, use Ventoy for now.

The installer image, for Ventoy

June USB checks the image's SHA-256 itself, so with June USB you can skip this part. You only download the image yourself for the Ventoy way, or to give it to June USB with Use an ISO file I already have. For Ventoy, you need two downloads:

  • Ventoy, a free tool that turns a USB stick into a boot menu. Download version 1.1.18 for Windows or Linux from SourceForge. Newer versions are on the official site, ventoy.net. There's no Mac version; on a Mac, use June USB.
  • The installer image, june-local-live.iso (about 1.4 GB). Download it from downloads.project-july.org/installer/latest.

Download installer 0.7 Ventoy for Windows Ventoy for Linux

Step 2

Make the USB stick

Use a stick of at least 16 GB. That's enough for the installer and one oven backup; 32 GB is better. USB 3 makes the backup much faster.

  1. 1

    Start June USB

    Open the app you downloaded. On Windows, it asks for administrator permission when it starts: it needs that to partition the stick.

  2. 2

    Get the installer

    The first screen shows the latest installer, about 1.4 GB, from downloads.project-july.org. Press Download and continue. June USB checks the download's SHA-256 itself. If you've downloaded the image before, choose Use an ISO file I already have instead; an image that isn't the published release is marked as such.

  3. 3

    Choose the USB stick

    The list shows each USB stick with its size and its current drive letters or names, so you can tell them apart. A stick that's too small is marked Can't use. Show all drives also lists SD cards and drives over 300 GB. The computer's built-in disks are never shown.

  4. 4

    Confirm, twice

    The next screen names the stick, for example Erase “Music”?, and lists what's on it. Tick I have copied everything I need from “Music” and press Erase and create the stick. Windows or macOS then asks once more, naming the stick again. June USB only goes ahead if you answer Yes.

  5. 5

    Wait a few minutes

    June USB prepares the stick, copies the installer, verifies the copy and makes the stick bootable. It reads every file back and checks it. Don't unplug the stick or close the window.

  6. 6

    Your stick is ready

    June USB ejects the stick itself, so it's safe to unplug. Then start the laptop from it: plug it into the laptop, not the oven, open the boot menu, choose the USB stick and then Install June Local - graphical.

Already have a June stick?

Sticks made with June USB are marked June stick in the list. Pick one and June USB offers Update the installer: it replaces only the installer and keeps everything on JUNE, including backups, logs and certificates. Choose Erase and start fresh to wipe it instead.

The finished stick

June USB splits the stick into two parts. Leave the small one alone. The large one is yours to use, and it's where the installer saves backups, logs and certificates.

  • Leave JUNEBOOT alone. It holds the installer. To put a newer installer on it, use Update the installer in June USB.
  • JUNE is ready for backups. It's exFAT, so it can hold the oven backup, one file of about 7.3 GB. The installer also adds june-logs/ and june-certs/ here.
  • Nothing else to copy. The stick starts the installer as it is.

Other way

Make the stick with Ventoy

On Linux, or if you'd rather use Ventoy, make the stick this way instead. You need Ventoy and the installer image from step 1.

Use a stick of at least 16 GB; 32 GB is better if the oven backup goes on the same stick.

On Windows

  1. Unzip the Ventoy download for Windows and run Ventoy2Disk.exe as Administrator.
  2. Pick your USB stick under Device. Check the name and size twice. Leave Show all devices off.
  3. Open Option › Partition Style and choose MBR.
  4. If the laptop uses Secure Boot, turn on Option › Secure Boot Support.
  5. Click Install and confirm both warnings. This erases the stick.

On Linux

  1. Install the tools Ventoy needs (Debian and Ubuntu shown):
sudo apt install dosfstools exfatprogs
  1. Unpack the Ventoy download for Linux and find your stick. Use the whole disk, like /dev/sdX, never a partition like /dev/sdX1:
lsblk -o NAME,SIZE,MODEL,TRAN,MOUNTPOINTS
  1. Install Ventoy. This erases the stick. Add -s for Secure Boot support.
sudo sh Ventoy2Disk.sh -i /dev/sdX

The finished Ventoy stick

Ventoy splits the stick into two parts. Leave the small one alone. The large one is where everything for Project July goes, and the installer finds it by its name, Ventoy.

  • Keep the name “Ventoy”. The installer looks for it to save logs, certificates and backups.
  • exFAT or NTFS, never FAT32. An oven backup is one file of about 7.3 GB, and FAT32 can't hold files over 4 GB. Ventoy's default, exFAT, is right.
  • Leave about 8 GB free if the backup will go on this stick.

Copy the installer and settings

  1. Open the large Ventoy drive and copy june-local-live.iso to the top level, not into a folder.
  2. Make a folder called ventoy there, and in it a text file called ventoy.json with this in it:
{
  "control": [
    { "VTOY_DEFAULT_MENU_MODE": "0" },
    { "VTOY_FILT_DOT_UNDERSCORE_FILE": "1" },
    { "VTOY_MENU_TIMEOUT": "3" },
    { "VTOY_DEFAULT_IMAGE": "/june-local-live.iso" }
  ]
}

This makes Ventoy start the installer by itself after 3 seconds, and hides the hidden files a Mac leaves behind. It's optional: without it, you pick the image from Ventoy's menu yourself.

  1. Eject the stick safely before you unplug it.

Step 3

Start the laptop from the stick

Use the laptop that will run the installer, not the oven. Its own system and files are left alone: take the stick out and restart to go back to normal.

  1. 1

    Open the boot menu

    Plug the stick in, switch the laptop on and press its boot-menu key straight away. It's often F12, F11, F9, F2 or Esc, and usually shown briefly on screen. Pick the USB stick. If it's listed twice, pick the one marked UEFI. On a Surface, hold Volume Down while it starts instead. On an Intel Mac, hold Option. Macs with Apple chips (M1 and later) and Windows laptops with ARM processors, such as the Surface Pro 9 with 5G or the Surface Pro X, can't start from this stick.

  2. 2

    Let the June Local menu start the installer

    It starts Install June Local - graphical after a few seconds, so you don't need to press anything. Choose text mode only if the graphical installer won't start. With a stick made with June USB, this is the only menu, and Secure Boot works as it is: there's no key to enroll. A Surface needs one setting changed first.

The June Local menu, simplified.

Surface and other Secured-core laptops

The installer starts with Secure Boot on, through a loader signed by Microsoft that almost every laptop accepts. Laptops sold as Secured-core PCs, including the Surface Pro 8 and later and the Surface Laptop 4 and later, come set to start only Windows: they skip the stick or say it isn't bootable. Allow it once, on a Surface like this:

  1. Shut it down. Hold Volume Up and press the power button until the Surface UEFI screen appears.
  2. Choose Security › Secure Boot › Change configuration, pick Microsoft & 3rd party CA and press OK. Secure Boot stays on.
  3. Choose Exit › Restart now and hold Volume Down while it starts, until the June Local menu appears.

Other Secured-core laptops, such as several Lenovo ThinkPads from 2022 on, have the same switch in their firmware settings, often called Allow Microsoft 3rd Party UEFI CA. Windows starts normally either way, and you can switch it back when you're done. This applies to Ventoy sticks too.

A Surface Pro 9 with 5G, and every Surface Pro X, has an ARM processor instead of an Intel one. It can't start the installer, however the stick is made; use another laptop.

Only for Ventoy sticks

Two menus, one after the other. First Ventoy's menu, which starts june-local-live.iso after 3 seconds. Then the June Local menu, as above. Both are expected; you don't need to press anything.

Secure Boot can stop a Ventoy stick. Many laptops have Secure Boot switched on. If you see a blue Verification failed or MokManager screen the first time, do one of these:

  • Enroll Ventoy's key (needs Secure Boot Support when you install Ventoy): choose Enroll key from disk, open VTOYEFI, pick ENROLL_THIS_KEY_IN_MOKMANAGER.cer, then Continue, Yes and Reboot. You only do this once per laptop.
  • Or switch Secure Boot off in the laptop's firmware settings (BIOS/UEFI) and start again. You can switch it back on afterwards.

Ventoy's menu, simplified. Your Ventoy version's colours and layout may differ.

The installer copies itself into the laptop's memory as it starts, so once it's running the stick can come out. That's useful if you want to save the backup to a different drive.

Every job

Put the oven in recovery mode

After you pick a job and its options, the installer shows this screen. These are its steps:

  1. Connect the oven to the laptop with the micro-USB cable. Use a port on the laptop itself, not a hub.
  2. Press and hold SW2 (force recovery) on the oven's board.
  3. Switch the oven's power on and keep holding SW2 for about 10 seconds.

Waiting for the oven updates by itself. When it says the oven is found, let go of SW2, wait a few seconds and press the job's button: Install June Local, Start backup or Erase oven and restore. The newest installer starts the job by itself after 3 seconds; press Back to stop it.

The oven's fans spin up and stay loud while it works. That's normal.

Install June Local

  1. 1

    Choose Install June Local

    The Oven name is how the oven appears on your network: the default, june, makes it june.local. The certificate covers june.local, june2.local and june3.local, so use june2 or june3 for a second or third oven. For a certificate for the oven's IP address, or a name of your own, use Install with your own CA. Leave Keep June Local after a factory reset off, as it starts, unless you want June Local to survive a factory reset. Press Next: connect the oven.

  2. 2

    Put the oven in recovery mode

    As above, then press Install June Local.

  3. 3

    Wait for “June Local is installed”

    About two minutes. The tracker at the top shows which stage it's on. Keep the oven connected and powered, and don't unplug anything until you see the success screen.

  4. 4

    Restart the oven and check it

    Unplug the oven's power and the USB cable. Wait 10 seconds, plug the power back in and let the oven start normally. From a phone or computer on the same network, open http://<oven-ip>/local to see the June Local status page, or scan its code on the success screen. Pair from the app or Home Assistant, and close the oven up only once that works.

Install with your own CA

For a certificate authority of your own instead of June's certificate. Enter the oven's address on your network (for example 192.168.1.50, reserved for the oven in your router) and a hostname: june.local, or a name of your own, which you then add to your own DNS. The installer creates the CA, signs a certificate for that address and name, and saves both in june-certs/ on the stick. After the install, put the CA on your phone (on Android: Settings › Security › Install a certificate › CA certificate) and pair using the oven's address. Keep June Local after a factory reset works here too, and keeps the CA as well.

Back up and restore

A backup is a complete copy of the oven's storage: one file of about 7.3 GB (7.8 GB as most computers count it). Make one before you install anything.

Back up the oven

  1. Choose Back up the oven, then the drive. The stick you started from is listed if it has room: as June USB (current boot USB) for a stick made with June USB, or Ventoy (current boot USB) for a Ventoy stick.
  2. Keep the folder (june-backups) and file name it suggests, or change them. Press Next: connect the oven.
  3. Put the oven in recovery mode and press Start backup. It takes 15 to 30 minutes.
  4. The installer saves the .img file with a .sha256 checksum next to it. Unplug the drive safely, then the oven's power and USB cable.

Not enough room on the stick?

The installer runs from the laptop's memory, so you can pull the USB stick out once it's running and plug in a second drive. Press Rescan drives and pick it. Use exFAT, NTFS or ext4 with at least 8 GB free.

Restore a backup

  1. Choose Restore a backup, pick the drive and press Find backups. Select the image.
  2. Read the warning and type RESTORE to confirm. Restoring removes June Local and anything that changed since the backup.
  3. Put the oven in recovery mode and press Erase oven and restore. Don't unplug the oven until it's finished.

Optional

Use your phone

You can follow and run every job from a phone, handy when the laptop is on the kitchen counter and you're crouched by the oven. Press Use your phone instead or Phone at the top, and scan the code.

  • The phone must be on the same network as the laptop.
  • Anyone who scans the code can control the installer. Switch Allow a phone on this network off when you're done; that disconnects phones and makes a new code.
  • After a custom install, the phone can download the CA from here.

Text mode

If the graphical installer won't start, choose text mode (basic UI) in the June Local menu. It does the same jobs and writes the same logs:

1) Install June Local
2) Install with your own CA
3) Back up the oven
4) Restore a backup
5) Exit installer and reboot

Help

If something goes wrong

A failed job shows the reason with Try again and Back to start. Every job also writes a log to june-logs/ on the USB stick (on JUNE, or on the Ventoy drive of a Ventoy stick); include it if you ask for help.

Do

  • Use a USB 3 port on the laptop itself
  • Keep the oven powered and connected for the whole job
  • Wait for the success screen before unplugging
  • Test the oven before closing it up

Don't

  • Unplug the oven during an install or restore
  • Use FAT32 for the backup drive
  • Change JUNEBOOT, or rename the Ventoy drive
  • Worry about the fans: running fast is normal

For the curious

What's inside

The installer image is a small Debian 12 system that runs entirely from the laptop's memory. It puts two programs on the oven, both written in Go and built for the oven's processor.

june-local

The local server that replaces June's cloud on your network. It answers the oven and the app the way June's servers did.

june-camerad

The camera bridge. It takes pictures from the oven's own camera service, without opening the camera itself, and streams them to the app and Home Assistant.

The source code for both will be published on GitHub alongside the installer.
